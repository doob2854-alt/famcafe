# 우리가족 카페 & 나들이 지도 (PWA 프로토타입)

17개월 아기 + 반려견 가족을 위한 카페 기록 지도. 빌드 도구 없이 파일만 올리면 바로 돌아가는 React PWA입니다.

## 파일 구성
```
family-outing-map/
├─ index.html        ← 앱 전체 (React 18 + Tailwind + Leaflet 지도, CDN 로드)
├─ manifest.json     ← 홈 화면 앱 설정 (이름, 아이콘, standalone 전체 화면, 테마색)
├─ sw.js             ← 서비스 워커 (오프라인 실행, 지도 타일·사진 캐시)
└─ icons/            ← 192/512/maskable/apple-touch 아이콘
```

## ⚠️ 꼭 HTTPS로 올려야 앱 설치가 됩니다
PWA(서비스 워커·설치)는 **https** 주소에서만 동작합니다. 파일을 더블클릭(file://)해서 열면 화면은 보여도 설치는 안 돼요.

가장 쉬운 방법 (무료, 5분):
1. **Netlify Drop** — https://app.netlify.com/drop 에 `family-outing-map` 폴더를 통째로 끌어다 놓기 → https 주소가 바로 생김
2. **GitHub Pages** — 저장소에 파일 업로드 → Settings → Pages → 브랜치 선택
3. **Vercel** — 폴더 업로드 후 배포

PC에서 미리 보기: 폴더에서 `npx serve .` 실행 후 http://localhost:3000

## 📱 홈 화면에 추가하기
앱이 처음 열리면 2초 뒤 설치 안내 시트가 자동으로 뜹니다 (오른쪽 위 `📲 앱 설치` 버튼으로 다시 열 수 있음).

- **아이폰**: 반드시 **Safari**로 접속 → 공유 버튼 ⬆︎ → '홈 화면에 추가'
  (카카오톡·인스타 링크로 열면 내부 브라우저라 메뉴가 없어요. Safari로 열기 선택)
- **안드로이드**: Chrome/삼성 인터넷 → '앱 설치' 버튼이 바로 동작 (또는 ⋮ → 홈 화면에 추가)

설치 후에는 주소창 없이 전체 화면으로 열리고, 노치·홈 인디케이터 영역도 안전하게 비켜 갑니다.

## 기능
- 상단 지도 + 하단 카드 리스트 (지도 핀 ↔ 카드 서로 연동, 핸들로 지도 접기)
- 카드: 사진, 이름, 별점, 한 줄 메모, 🪑아기 의자 / 👶유모차 진입 / 🐶반려견 동반 배지 (없는 항목은 흐리게 취소선)
- 필터: 반려견 동반만 / 유모차 가능만 / 아기 의자 (중복 선택 가능)
- 방문 기록 추가·수정·삭제: 이름, 주소, 지도 탭으로 위치 지정(현재 위치 버튼), 날짜, 별점, 사진(샘플 / 휴대폰 앨범·촬영 / URL), 태그, 한 줄 메모, 후기
- 상세 화면에서 카카오맵 길찾기 / 네이버지도 검색 바로가기
- 데이터는 기기 안(localStorage)에 저장 → 오프라인에서도 기록 열람 가능

## 알아 둘 점 (프로토타입 한계)
- **부부 간 데이터 공유는 아직 안 됩니다.** 기록은 각자 폰에만 저장돼요. 함께 쓰려면 다음 단계로 Firebase/Supabase 같은 백엔드 연결이 필요합니다.
- 주소로 위치를 자동 검색하진 않고, 지도에서 직접 핀을 찍는 방식입니다 (카카오 지도 API 키를 받으면 주소 검색으로 바꿀 수 있음).
- 앨범 사진은 기기 저장 용량(약 5MB)을 쓰므로 자동으로 900px로 줄여 저장합니다.
- 브라우저에서 Babel로 JSX를 변환하므로 첫 실행이 1~2초 걸립니다. 정식 앱으로 키울 때는 Vite로 빌드하면 빨라집니다.
- 기본 예시 카페 4곳은 가상의 장소입니다. 삭제하고 쓰시면 돼요.
- 코드를 고친 뒤 폰에 반영이 안 되면 `sw.js`의 `VERSION` 값을 올려 주세요.
